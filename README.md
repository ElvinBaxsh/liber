# LIBER Travel — Website

Website for LIBER Travel, a destination management company (DMC) offering tours and travel services.

## Features

- Pages: Home, About, Services, Tours, Contact (React Router)
- Hero slider with multiple banners (react-slick)
- Reusable layout with navbar and footer
- Content kept in data files, so pages are easy to update
- Responsive design with Tailwind CSS

## Tech Stack

React · Vite · React Router · Tailwind CSS · react-slick · Lucide / React Icons

## Getting Started

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```
